# 功能分析

## 範圍與交付要求

記錄目標、真實入口、來源根目錄、讀者、已確認要求、排除範圍與必要交付項。
本模板是無指定格式時的起點；有使用者模板時保留原結構。

## 功能與行為

說明前置條件、操作／呼叫、正常與替代／失敗結果、狀態變化、副作用。
需要流程圖時使用 Mermaid；只放理解或驗收需要的圖。

## 相關技術與資料

按要求說明資料、API、交易、UI 或批次，不為了填滿模板新增無關內容。

## 證據與覆蓋

| ID | 觸發條件／要求 | 行為或主張 | 來源路徑＋符號／行號 | 事實分類 | 文件位置／覆蓋狀態 |
|---|---|---|---|---|---|

事實分類區分 code-derived／inferred／business-input，並區分 AS-IS／approved-requirement／proposed。
由來源與需求列出行為，再核對文件；缺漏標 gap，不刪掉那一列。多份文件共用時可抽到 EVIDENCE.md。

## 限制與待確認事項

| 問題 | 已查證內容 | 缺少資訊 | 影響要求 | 是否阻擋 |
|---|---|---|---|---|

沒有待確認事項時寫「無」。審查結論放 REVIEW.md，不在此重複複製分數或檔案指紋。
